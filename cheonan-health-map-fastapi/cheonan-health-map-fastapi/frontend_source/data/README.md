# 대시보드 사용자료

이 폴더에는 대시보드의 지표·가중치·정책추천을 확인하는 데 사용한 원자료와 분석 파일을 둡니다. 앱에 직접 연결된 가공 데이터와 코드 파일은 `app/`에 있습니다.

## 01 인구

- `01_KOSIS_인구/6월 인구현황-게시용.xlsx`: 천안시 전체·행정구역 인구 기준 확인
- `app/data/cheonan-age-population-2026-06.csv`: KOSIS `101_DT_1B04005N_M_2026`에서 천안시 31개 행정구역과 2026년 6월만 추린 앱 사용 CSV

전국 단위 원본 `101_DT_1B04005N_M_2026.csv`는 약 37.7MB이므로 저장소에는 넣지 않았습니다. 원본 표 식별자와 위 추출 CSV로 같은 범위를 재현할 수 있습니다.

## 02 천안시 원자료

- `02_천안시_원자료/의료기관_20260723172839.xlsx`: 읍·면·동별 의료기관 수
- `02_천안시_원자료/의약품_등_판매업소_20260723173542.xlsx`: 읍·면·동별 약국 수
- `02_천안시_원자료/독거노인_현황_성별__20260723173327.xlsx`: 2019년 독거노인·기초생활·저소득 자료
- `02_천안시_원자료/독거노인_현황_연령별__20260723173332.xlsx`: 독거노인 연령구성 참고
- `02_천안시_원자료/장애인_등록현황_20260723173318.xlsx`: 2023년 등록장애인 자료
- `02_천안시_원자료/건강_병원_충남천안시.csv`: 시설 상세 명단·주소·좌표 확인

## 적용 시 유의사항

- 인구는 2026년 6월, 독거노인은 2019년, 장애인은 2023년, 의료기관·약국은 2024년 기준입니다.
- 불당1동·불당2동의 2019년 독거노인 하위구성은 원자료가 불당동으로 통합돼 있어 임의 배분하지 않았습니다.
- 노인의료복지시설·보건소 인력처럼 구 단위로만 제공된 자료는 읍·면·동별 지표에 넣지 않았습니다.
