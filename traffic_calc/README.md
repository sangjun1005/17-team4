# 천안시 교통 취약성 계산 모듈

천안시 읍·면·동 전체를 대상으로 순회진료 우선 검토에 참고할 **교통 취약성 보조지표**를 계산하는 독립 모듈입니다. 이번 모듈에서는 사용자가 정한 두 요소만 반영합니다.

## 사용하는 자료

| 파일 | 역할 |
|---|---|
| `route_stops_cheonan.csv` | 노선별 정류장과 `1일운행횟수`를 이용해 읍·면·동별 운행 공급량과 고유 정류장 수를 집계 |
| `천안시_버스정류장_천안시만_20251031.csv` | 천안시 공식 정류장 위치·읍면동 매핑을 기준으로 읍·면·동별 고유 정류장 수를 산출 |
| `천안시_시내버스운수업체별노선현황_20260310.csv` | 노선별 `1일운행횟수(회_편도기준)`의 원본 기준값. 노선-정류장 행마다 이 노선별 운행횟수를 적용 |
| `cheonan-subdivisions.json` | 천안시 31개 읍·면·동의 경계와 읍·면·동별 면적 계산에 사용 |

면적은 별도의 수기 입력값이 아니라 GeoJSON 경계 좌표를 지역 평면으로 투영해 계산합니다. 따라서 현재 결과의 면적 열에는 `GeoJSON 경계 좌표 계산`이라고 표시됩니다. 추후 같은 기준연도의 공식 통계연보 면적을 확보하면 그 열만 교체해 재계산할 수 있습니다.

## 점수 산식

1. **일일 운행 공급량**
   - `route_stops_cheonan.csv`에서 읍·면·동에 속한 노선-정류장 연결을 가져옵니다.
   - 각 노선의 운행횟수는 `천안시_시내버스운수업체별노선현황_20260310.csv`의 `1일운행횟수(회_편도기준)`을 우선 적용합니다. 원자료의 편도 기준값을 그대로 사용하며 임의로 2배 환산하지 않습니다.
   - 노선 자료의 정류장 집계는 검증용으로 함께 저장하며, 같은 읍·면·동 안에서 `(노선번호, 정류장코드)`가 같은 행은 한 번만 반영합니다.
   - 위치정보 자료에 없는 노선 정류장 코드는 별도 검증 대상이며, 현재 제공된 자료에서는 모두 위치정보 자료와 일치합니다.
   - `1일운행횟수`를 합산한 값이며, 실제 승객 수나 실제 교통량이 아닌 **예정 운행 공급량**입니다.

2. **정류장 밀도**
   - `고유 정류장 수 ÷ 면적(km²)`
   - 정류장이 적고 면적이 넓을수록 낮아집니다.

3. **0~100 취약점수**
   - 천안시 31개 읍·면·동을 서로 비교하는 역 min-max 정규화를 적용합니다.
   - 값이 낮은 지역이 더 취약하도록 다음처럼 뒤집습니다.
   - `운행공급부족도 = 100 × (1 - (운행공급량 - 최솟값) / (최댓값 - 최솟값))`
   - `정류장밀도부족도 = 100 × (1 - (정류장밀도 - 최솟값) / (최댓값 - 최솟값))`
   - `교통취약점수 = 운행공급부족도 × 0.5 + 정류장밀도부족도 × 0.5`
   - 두 지표의 범위가 모두 0~100이므로 두 요소를 같은 비중으로 비교할 수 있습니다. 동률인 지표는 모든 지역을 50점으로 처리합니다.

이 모듈에는 고령인구, 독거노인, 의료기관 수, 노선 수를 추가하지 않습니다. 해당 요소는 종합 취약성 화면에서 별도 모듈로 다루어 교통 지표와 이중 반영되지 않도록 합니다.

## 실행 방법

```powershell
cd "C:\Users\KDS01\Downloads\트래픽_칼큐"
python .\traffic_calc.py
```

다른 파일이나 출력 위치를 지정할 수도 있습니다.

```powershell
python .\traffic_calc.py --routes .\route_stops_cheonan.csv --stops .\천안시_버스정류장_천안시만_20251031.csv --route-master .\천안시_시내버스운수업체별노선현황_20260310.csv --areas .\cheonan-subdivisions.json --output .\traffic_vulnerability_scores.csv
```

실행하면 `traffic_vulnerability_scores.csv`가 생성되며, 교통 취약점수 내림차순 순위와 원자료(면적, 정류장 수, 일일 운행 공급량, 정류장 밀도)를 함께 확인할 수 있습니다.

## 해석상의 주의점

- `1일운행횟수`는 시간표·노선 자료에 기반한 공급량입니다. 승하차 인원, 실제 통행량, 운행 지연을 의미하지 않습니다.
- 노선 데이터에 방향 구분이 없는 경우 동일 노선·정류장 조합은 하나로 세므로, 방향별 운행을 별도로 제공하는 최신 자료가 있으면 집계키를 확장할 수 있습니다.
- 점수는 천안시 내부의 상대 순위입니다. 다른 도시의 점수와 직접 비교하지 않습니다.
