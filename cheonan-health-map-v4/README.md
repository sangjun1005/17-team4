# 천안시 읍면동 의료취약지역 지도

천안시 31개 읍·면·동을 대상으로 고령화·의료·교통 접근성 지표를 지도와 비교 대시보드로 보여주는 웹 애플리케이션입니다.

## 주요 기능

- 천안시 31개 행정구역 경계와 취약도 단계별 지도 색상
- 동일가중치·목적기반·CRITIC 가중치 모형 비교
- 전체 행정구역 취약 우선순위와 지역 선택
- 65세 이상 인구, 연령구간, 독거노인, 등록장애인 비교 대시보드
- 선택 지역의 고령·교통 취약도, 의료자원 및 정책 추천 표시
- 지도 집중 모드와 화면 크기에 따른 안전영역 조정

## 실행 방법

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

검증 명령:

```bash
pnpm lint
pnpm test
```

## 데이터 구성

앱에서 직접 읽는 인구 원자료는 [app/data/cheonan-age-population-2026-06.csv](app/data/cheonan-age-population-2026-06.csv)입니다. KOSIS 2026년 6월 자료에서 천안시 31개 행정구역만 추린 파일입니다.

분석에 사용한 원자료·가중치 근거는 [data/README.md](data/README.md)에 목록과 출처 기준을 정리했습니다. 전국 단위 KOSIS 원본 CSV(약 37.7MB)는 저장소 용량을 불필요하게 늘리지 않도록 제외했으며, 천안시 추출본과 원본 식별 정보로 재현할 수 있습니다.

## 자료 기준연도

| 항목 | 기준연도 |
| --- | --- |
| 주민등록 인구·연령구간 | 2026년 6월 |
| 의료기관·약국 | 2024년 |
| 독거노인 | 2019년 |
| 등록장애인 | 2023년 |
| 버스정류장 위치 | 2025년 10월 31일 |

## 해석 유의사항

- 취약도 점수와 순위는 행정지원 우선순위 비교를 위한 지표이며 개인 의료진단이 아닙니다.
- 기준연도가 다른 지표를 함께 비교하므로 화면의 기준연도를 확인해야 합니다.
- 불당1동·불당2동의 2019년 독거노인 하위 구성은 원자료가 불당동으로 통합돼 있어 임의 배분하지 않았습니다.
