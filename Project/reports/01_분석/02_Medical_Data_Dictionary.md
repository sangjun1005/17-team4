# Medical Data Dictionary

## 1. 데이터 개요

| 항목 | 내용 |
|---|---|
| 데이터명 | 천안시 읍면동별 의료기관 현황 |
| 데이터 유형 | 공공 통계 기반 의료자원 데이터 |
| 분석 단위 | 천안시 읍·면·동 |
| 주요 목적 | 지역별 의료자원 분포를 파악하고 고령인구 데이터와 결합하여 방문의료 우선 검토지역을 찾기 위함 |
| 주요 활용 | 의료기관 분포 분석, 공공의료기관 보완 여부 확인, 고령인구 대비 의료자원 밀도 계산 |
| 주의사항 | 상세 의료기관 좌표 데이터는 법정동 기준, 인구 데이터는 행정동 기준이어서 직접 병합하지 않고 지도 시각화용으로만 활용 |

## 2. 원본 데이터 구조

원본 파일은 첫 번째 행에 `병원수`, `병상수`, `소계` 등의 하위 항목명이 한 번 더 포함된 다중 헤더 구조였다.

전처리 과정에서 다음 작업을 수행하였다.

- 첫 번째 중복 설명 행 삭제
- 읍면동 지역 컬럼명 통일
- 분석에 필요한 컬럼만 선택
- `-` 값을 의료기관이 없는 경우로 해석하여 `0`으로 변환
- 숫자형 컬럼을 정수형으로 변환
- 전체 합계와 구 단위 집계행은 읍면동 비교에서 제외

## 3. 주요 컬럼 정의

| 컬럼명 | 자료형 | 단위 | 설명 | 활용 |
|---|---:|---:|---|---|
| 지역 | 문자열 | - | 천안시 읍·면·동 이름 | 인구 데이터와 병합하는 기준 컬럼 |
| 의료기관수 | 정수 | 개 | 병원·의원·치과·한의원 등 일반 의료기관의 합계 병원 수 | 지역별 일반 의료자원 공급 규모 분석 |
| 보건소 | 정수 | 개 | 해당 지역의 보건소 수 | 공공의료 자원 분석 |
| 보건지소 | 정수 | 개 | 해당 지역의 보건지소 수 | 읍·면 지역의 공공의료 거점 분석 |
| 보건진료소 | 정수 | 개 | 해당 지역의 보건진료소 수 | 의료취약지역 보완 기능 분석 |
| 건강생활지원센터 | 정수 | 개 | 건강생활지원센터 수 | 예방 중심 건강관리 자원 확인 |
| 종합병원 | 정수 | 개 | 종합병원 수 | 병원급 의료자원 분석 |
| 요양병원 | 정수 | 개 | 요양병원 수 | 고령층 관련 의료자원 분석 |
| 일반병원 | 정수 | 개 | 일반병원 수 | 병원급 의료자원 분석 |
| 의원 | 정수 | 개 | 의원 수 | 일차의료 공급 규모 분석 |
| 치과 병·의원 | 정수 | 개 | 치과 병원 및 치과의원 수 | 참고 의료자원 |
| 한방병원 | 정수 | 개 | 한방병원 수 | 참고 의료자원 |
| 한의원 | 정수 | 개 | 한의원 수 | 참고 의료자원 |

## 4. 생성한 파생변수

| 파생변수 | 계산식 | 의미 |
|---|---|---|
| 공공 기관 수 | 보건소 + 보건지소 + 보건진료소 | 해당 지역에서 공공이 제공하는 기본 의료자원 규모 |
| 고령인구1000명당의료기관수 | 의료기관수 ÷ 65세 이상 인구 × 1,000 | 고령인구 규모를 고려한 일반 의료기관 공급 수준 |
| 우선 검토 후보 | 65세 이상 인구가 평균 이상이고 의료기관 수가 평균 미만인 지역 | 방문의료 추가 검토가 필요한 1차 후보지역 |

## 5. 결측치 및 이상값 처리 기준

| 항목 | 처리 |
|---|---|
| `-` 값 | 해당 기관이 없는 것으로 보고 0으로 변환 |
| 첫 번째 중복 설명 행 | 삭제 |
| 전체 합계·동남구·서북구 집계행 | 읍면동 비교 분석에서는 제외 |
| 상세 의료기관 데이터의 읍면동 결측 | 지도 분석 시 주소 또는 좌표 기반 보완 검토 |
| 숫자형 변환 오류 | 문자열과 기호를 먼저 정리한 뒤 `astype(int)` 적용 |

## 6. 데이터 활용 시 주의사항

1. `의료기관수 = 0`은 의료서비스가 전혀 없다는 뜻이 아니다. 보건지소와 보건진료소가 별도로 존재할 수 있다.
2. 의료기관 개수만으로 실제 의료 접근성을 완전히 판단할 수 없다. 이동거리, 진료과목, 병상 수, 운영시간, 인접 지역 이용 가능성 등이 추가로 필요하다.
3. 본 데이터는 지역 우선순위의 최종 결정용이 아니라, 추가 검토지역을 찾기 위한 기초 지표로 사용한다.
4. 실제 방문 대상자 결정은 보건소·의료기관 내부 시스템의 개인 단위 정보와 의료진 판단을 통해 이루어져야 한다.
