# 천안시 의료취약지역 지도

천안시의 고령화·의료 데이터를 분석해 의료취약지역을 찾아내고, 순회진료 우선순위를 제안하는 프로젝트입니다.

---

## 왜 이 프로젝트인가

천안시 전체 고령인구비율은 **15.77%**로 이미 고령사회 기준(14%)을 넘었고, 동면 등 일부 읍·면은 **54.72%**에 달합니다. 반면 의료기관이 아예 없는 지역도 **4곳**입니다. 인구·의료기관·독거노인·등록장애인·대중교통 데이터를 종합해 어느 지역이 얼마나 취약한지를 계산하고, 지도와 대시보드로 보여줍니다.

## 무엇을 만들었나

- 동일가중치 / 목적기반 / CRITIC / 퍼지 AHP, 네 가지 방식으로 의료취약지역 점수를 계산
- 지도 위에서 지역을 선택하면 가중치별 결과와 취약 순위를 바로 비교할 수 있는 웹 대시보드
- 같은 계산 로직을 그대로 옮긴 FastAPI 버전 (React 없이도 실행 가능)
- 날씨와 질병 발생의 관계를 분석한 별도 통계 모델

## 저장소 구조

| 폴더 | 내용 |
|---|---|
| `cheonan-health-map-v4` | 웹 대시보드 최신 버전 (Next.js, 지도·가중치 비교·취약순위) |
| `cheonan-health-map-v3` | 이전 버전. README 내용이 v4와 동일해 실제 차이가 무엇인지 별도 정리가 필요함 |
| `cheonan-health-map-fastapi/cheonan-health-map-fastapi` | v3/v4의 화면과 계산 로직을 유지한 FastAPI 서버 버전 |
| `cheonan-health-map-v4/data` | 대시보드 분석에 쓰인 원자료와 가중치 산출 파일 |
| `project` | 초기 인구·의료기관 EDA, 전처리 노트북, 분석 리포트 |
| `disease`, `data` | 날씨-질병 위험도 분석 |
| `reports` | 분석 리포트 |
| `memo` | 작업 메모 |

`Project`와 `project` 폴더가 대소문자만 다르게 함께 있어 하나로 정리하는 것을 권장합니다.

## 실행 방법

**웹 대시보드**

```bash
cd cheonan-health-map-v4
pnpm install
pnpm dev
```

**FastAPI 버전**

```bash
cd cheonan-health-map-fastapi/cheonan-health-map-fastapi
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

FastAPI 버전은 실행 후 `http://127.0.0.1:8000`에서 화면을, `http://127.0.0.1:8000/docs`에서 API 문서를 볼 수 있습니다. 두 버전 모두 지도 타일을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
